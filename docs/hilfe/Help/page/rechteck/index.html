Rechteck zeichnen

Rechtecke ziehen Sie von einer Ecke zur gegenüberliegenden auf; abgerundete Ecken sind ein Maßfeld.

Wählen Sie das Rechteck (Taste R), drücken Sie an einer Ecke und ziehen Sie zur gegenüberliegenden. Beim Loslassen ist das Rechteck fertig und ausgewählt.

Unter Maße und Eigenschaften stellen Sie Mitte, Breite und Höhe genau ein; der Eckradius rundet die Ecken ab. Der Eckradius wirkt auch auf die Werkzeugwege.
