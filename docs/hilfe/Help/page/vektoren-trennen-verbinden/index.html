Vektoren trennen, löschen und verbinden

Vektoren an Kreuzungen teilen, einzelne Stücke entfernen und offene Enden verbinden.

WerkzeugSo geht es
Trennen (T)Einen Vektor anklicken: Er wird an jeder Kreuzung mit anderen Vektoren geteilt.
Vektor löschenEinen Vektor oder ein getrenntes Stück anklicken: Es wird entfernt. So lassen sich überstehende Enden nach dem Trennen wegnehmen.
VerbindenZwei Punkte nacheinander anklicken: Sie werden mit einer Linie verbunden. Klicken Sie beide Enden eines Linienzugs an, wird er geschlossen.

Geschlossene Vektoren brauchen Sie für Taschen und Ausschnitte mit Innen- und Außenseite; offene Linien eignen sich für Profile und Nuten.
