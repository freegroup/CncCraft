Dateien speichern und öffnen Neu in CncCraft

Projekte werden als <code>.cnccraft</code>-Dateien gespeichert und enthalten Zeichnung, Ebenen, Variablen, Bedingungen und Werkzeugwege.

BefehlWirkung
Datei ▸ Neu …Beginnt einen neuen Job (Neuen Job erstellen und einrichten).
Datei ▸ Öffnen …Lädt ein Projekt (.cnccraft).
Datei ▸ Beispiel öffnenLädt das mitgelieferte Beispiel.
Datei ▸ Speichern / Speichern unter …Schreibt das Projekt in eine Datei.
Datei ▸ Werkzeugwege speichern …Schreibt die Maschinendatei (G-Code), siehe Werkzeugwege speichern.

Ungespeicherte Änderungen

Hat die Zeichnung Änderungen, die noch nicht gespeichert sind, steht hinter dem Dateinamen oben rechts ein Punkt (●). Wollen Sie dann das Programm schließen, einen neuen Job beginnen, eine andere Datei oder das Beispiel öffnen, fragt CncCraft zuerst „Möchten Sie die Änderungen … speichern?“:

  • Speichern: speichert (bei einer neuen Datei fragt CncCraft nach dem Namen) und macht dann weiter. Brechen Sie das Speichern ab, bleibt die Frage offen.
  • Nicht speichern: macht ohne Speichern weiter; die Änderungen gehen verloren.
  • Abbrechen (oder Esc): nichts passiert, Sie arbeiten weiter.

Das Projekt ist eine Textdatei im JSON-Format; ältere Dateien mit der früheren Endung .funke lassen sich weiterhin öffnen.
