Tools and cutting values

Every toolpath gets a tool with matching values for feed, speed and stepdown.

In a toolpath's form you pick from a built-in list in the Tool field. It holds, per material, tools in several diameters with values that suit that material:

  • End mills for profiles, cut-outs and pockets,
  • Ball-nose cutters,
  • V-bits with a tip angle for V-carving,
  • Drills for holes.

Which tools appear depends on the job's material (Create and set up a new job). When a tool is chosen, the form takes its values; you can change each one.

FieldMeaning
Start depthWhere the cut begins, from the material surface (0 = surface).
Cut depthHow deep in total. For a cut-out the default is the material thickness.
StepdownHow much deeper the cutter goes per pass. Depth and stepdown give the number of passes.
StepoverThe sideways distance between two passes for pockets and V-carving, in millimetres and as a percentage of the cutter diameter.
Spindle speedSpindle revolutions per minute (rpm).
Feed rateCutting speed in mm/min.
PlungeSpeed when plunging into the material in mm/min.
Tool no.The number that stands in the G-code file for the tool change.

Start and cut depth take formulas and variables, for example platte_d/2 or platte_d (Formulas in dimension fields).

Warnings

Every material has limits: the highest feed, the speed range and how deep the cutter may go per pass (for example two thirds of the diameter in hardwood). If a field exceeds a limit, a warning below it states what the material allows. Save anyway and CncCraft also writes the warning into the header of the G-code file.

The shipped cutting values are starting points. Always check feed, speed and stepdown for your router and material, and mill a test in scrap material first.
