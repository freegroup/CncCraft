Installation

CncCraft wird aus dem Quelltext gebaut; das Skript <code>build.sh</code> erzeugt daraus die Pakete für macOS, Windows und Linux.

Alle Pakete entstehen mit einem Aufruf von build.sh (oder kurz make) im Ordner des Programms. Fertige Dateien landen im Unterordner dist/.

BefehlErgebnisLäuft auf
./build.sh macCncCraft.app, .zip und .dmg für Apple Siliconeinem Mac
./build.sh mac-inteldasselbe für Intel-Macseinem Mac
./build.sh windowsCncCraft.exe, .zip und – mit Inno Setup – ein InstallationsprogrammWindows
./build.sh linux.tar.gz und .deb (x86_64)Linux
./build.sh allalles, was auf diesem Rechner möglich ist

Voraussetzungen

  • Die Programmiersprache Rust mit cargo (zum Übersetzen).
  • macOS 12 oder neuer für die Mac-Pakete.
  • Für das Windows-Installationsprogramm: Inno Setup.

Pakete bei GitHub bauen lassen

Wer keine eigenen Windows- oder Linux-Rechner hat, kann alle Pakete bei GitHub bauen lassen: Die mitgelieferte Arbeitsanweisung .github/workflows/release.yml startet, sobald ein Versions-Tag wie v0.1.0 hochgeladen wird, und hängt die Pakete an die Veröffentlichung.

Die Mac-App ist nur „ad hoc“ signiert. Auf fremden Macs erscheint daher beim ersten Start eine Sicherheitswarnung; ohne Apple-Entwicklerkonto lässt sie sich nicht vermeiden. Die Wege für Windows und Linux sind beschrieben, wurden aber bisher nicht auf allen Systemen ausprobiert.

Prüfen, ob es läuft

Mit cnccraft --selftest führt das Programm einen Selbsttest aus und meldet jeden Schritt. Mit cnccraft --screenshot bild.png speichert es ein Bild des Fensters, ohne dass Sie etwas bedienen müssen – so sind die Abbildungen dieser Hilfe entstanden.
