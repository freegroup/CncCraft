Skripte und Automatisierung Neu in CncCraft

Mit einem kleinen Skript steuern Sie CncCraft Schritt für Schritt – die sichtbare Maus führt jeden Klick vor. Ideal für kurze Videos für TikTok, Instagram & Co.

Dies ist eine Pilotfunktion (Beta). Skripte und der eingebaute Automatisierungs-Server sind neu, werden noch verfeinert und können sich ändern. Sie sind vor allem zum Aufnehmen von Demos gedacht; für die tägliche Arbeit braucht man sie nicht.

CncCraft kann ein Skript ausführen: eine einfache Liste von Befehlen, einer pro Zeile, die es ausführt, indem es die sichtbare Maus bewegt und die echten Knöpfe anklickt – es sieht also genau so aus, als würde jemand das Programm bedienen.

Das eignet sich gut, um kurze Demo-Videos für TikTok, Instagram oder YouTube Shorts zu bauen: der große sichtbare Zeiger, die eingeblendeten Beschriftungen und die ruhigen, wiederholbaren Bewegungen ergeben saubere Clips ganz ohne Hand. Nehmen Sie das Fenster auf, setzen Sie Titel und Untertitel, wählen Sie das Tempo – und lassen Sie das Skript zeichnen und fräsen, während die Maus jeden Schritt vorführt.

Das Skriptfenster

Öffnen mit Hilfe ▸ Skript…. Es ist ein eigenes Fenster, das Sie überallhin schieben können. Es hat einen Editor mit Autovervollständigung und Syntaxhervorhebung, einen Knopf Ausführen und Stopp, ein Fenster Befehlshilfe mit allen Befehlen und einen agent.md-Knopf, der eine vollständige Anleitung für einen KI-Assistenten kopiert.

Wie ein Skript aussieht

  • Ein Befehl pro Zeile, zum Beispiel draw_rectangle cx=50 cy=50 width=40 height=30.
  • Mit name = tool … merken Sie sich das Ergebnis unter einem Namen und verwenden es später als $name.id – so können Sie eine Form zeichnen und ihr einen Werkzeugweg geben.
  • Zeilen wie move_to, click, drag und type_text laufen über den sichtbaren Zeiger; screenshot, recording_start / recording_stop und window width=… height=… helfen beim Aufnehmen.
  • text_title und text_subtitle blenden eine Beschriftung ein, replay_speed stellt ein, wie schnell die Maus sich bewegt.

Einrasten aus dem Skript

Jeder Knopf hat einen Befehl, also kann ein Skript die drei Einrast-Methoden (Einrasten) wie jeden anderen ein- und ausschalten: snap_to_geometry (Bounding-Box), snap_to_center und snap_to_gap. So lässt sich in einer Demo Schritt für Schritt zeigen, wie eine Form an einer Kante, einer Mitte oder einem gleichen Abstand einrastet.

Automatisierungs-Server

Im Hintergrund sind dieselben Befehle ein Automatisierungs-Server, der in CncCraft nur auf Ihrem eigenen Rechner läuft (localhost). Ein KI-Assistent kann sich damit verbinden und eine Zeichnung für Sie bauen, während die sichtbare Maus jeden Schritt vorführt. Nichts verlässt Ihren Rechner.

Alle Befehle

Dies sind alle Befehle, die ein Skript (und der Automatisierungs-Server) versteht – genau die Menge, die auch der KI-Assistent in agent.md sieht. Die Befehlsnamen sind englisch.

Every line of a script is one of these commands. Parameters are written name=value; required ones are marked. Returns is what a later line can use through a variable (for example $name.id). This list is generated from the program itself, so it always matches your version.

agent_md

Get the agent guide (Markdown): what CncCraft and its script language are for, the syntax, coordinates and pacing rules, every command with its parameters and return value, and example scripts. Read it first to write scripts.

No parameters.

Returns: Text: the agent guide as Markdown.

state

Report the current job (size, material), the shapes (id, kind, centre, size in mm) and the toolpaths (index, name, tool, depth). Use it to find shape ids before adding toolpaths.

No parameters.

Returns: JSON {"job": {"width", "height", "thickness", "material"}, "selection": [ids], "shapes": [{"id", "kind", "cx", "cy", "width", "height"}], "toolpaths": [{"index", "name", "tool", "cut_depth"}]}.

No parameters.

Returns: JSON {"materials": [keys]}.

No parameters.

Returns: JSON {"material", "tools": [{"name", "kind", "diameter"}]}.

window

Report the window size, whether the cursor is still playing (busy), the MCP port, which side panels are open, the view (2d or 3d), the replay speed and the recording. With width and/or height (logical points), it resizes the window first — set a steady size before recording_start.

ParameterTypeRequiredValuesMeaning
heightnumbernoNew window height in points (optional; keeps the current height if left out).
widthnumbernoNew window width in points (optional; keeps the current width if left out).

Returns: JSON {"width", "height", "busy", "port", "panels": {"tools", "milling"}, "view", "replay_speed", "recording": path or null}.

drag_shape

Drag a shape with the visible mouse: the cursor goes to the shape, presses, glides and releases so the top-left corner of the shape's outline box lands at (left, top). It is the app's own drag, so the shape snaps to the grid and to construction lines (and attaches to a line it lands on), as by hand. Returns {"id", "from", "to"}.

ParameterTypeRequiredValuesMeaning
idnumberyesThe shape's id (from a drawing tool's result or the state tool).
leftnumberyesWhere the left edge of the shape should end up, in mm from the left edge of the material.
topnumberyesWhere the top edge of the shape should end up, in mm from the bottom edge of the material.

Returns: JSON {"id", "from": {"left", "top"}, "to": {"left", "top"}} — the place asked for; the shape may snap a little to the grid or a construction line (read it back with state).

add_toolpath

Create a milling toolpath, all through the UI: the visible mouse clicks the shapes to select them (Shift for the extra ones), opens the milling panel if needed, clicks the operation's button, types the depths into the editor's fields when given, and clicks Anwenden. Fields left out keep the material's standard value. All shapes must be on screen (run view_fit first if needed).

ParameterTypeRequiredValuesMeaning
kindstringyesprofile, cutout, pocket, slot, drill, vcarveThe milling operation: profile (along the outline), cutout (cut the part free), pocket (clear the inside), slot, drill (holes) or vcarve.
shape_idsarrayyesThe ids of the shapes to cut (from a drawing tool's result or the state tool).
cut_depthstringnoHow deep the cut goes in total (the 'Zieltiefe' field): a number in mm or a variable/formula like platte_d or platte_d/2 (optional).
max_depth_per_passstringnoThe most the cutter takes per pass (the 'Zustellung' field, 'Bohrtiefe je Hub' for drilling): a number in mm or a formula (optional).

Returns: JSON {"kind", "shape_ids": [ids], "cut_depth", "max_depth_per_pass"} — the toolpath is computed once the mouse has clicked Anwenden; read it back with state.
